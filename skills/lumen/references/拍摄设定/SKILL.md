# 拍摄设定

图像和视频共用的摄影参考。正文用中文，设备、镜头、胶片的品牌型号保留准确原名，可直接进入提示词。没有内部预设编号。

保留专业名称与具体参数。视角写明确的视场角，例如 `水平视场角 47°`；机位可写 `右前方 45°，向下俯拍 30°`。视场角、机位角度与取景内容分别明确。各表用于选择，示例按当前主体改写。

## 全片设定与分镜的层级

视频先确定一份全片统一设定，再写各镜头。机身、记录画幅、镜头组或光学系列、整体视觉风格在开头声明一次，整条视频共同使用。各镜头不重复列机身和风格，也不逐镜另选一套；用户明确要求混合设备或风格时再按指定范围安排。

同一场景的灯位、光源色温和白平衡在场景说明中写一次。换场景时只交代实际改变的照明和空间条件，机身与整体风格仍继承全片设定。

每镜分别设计视场角、景别与具体取景、机位与构图、光圈、景深、摄影机运动、动作、声音和切点。专业参数保持具体，例如 `水平视场角 47°、f/5.6、右前方 45°、向下 30°`；取景仍要点名当前主体与部位。

参数继承以全片或已明确的场景默认值为准：

- 已在统一设定写出的默认值，每镜省略即可；变化处给具体值。
- 单镜写出的临时值只在该镜有效，下一镜回到对应默认值；不自动继承上一镜的临时修改。
- 若本片没有声明某项默认值，就在使用该项的镜头中明确选择，不能用空白暗示一个未定义参数。
- 镜头组在全片确定，各镜选择不同视场角及需要的光学类型；需要时写清微距倍率，这不需要重新声明机身和风格。
- 统一设定已有的设备与风格，不在结尾“全程保持”中再抄一次；结尾只补必要的身份、道具、空间和声画关系。

原创方案可由助手主动选择参数设计值；保留或改写任务优先遵守用户已有要求。设备规格、产品事实和图片观察不能由设计值替代。专业参数用于表达生成意图，不承诺精确光学仿真或卡帧。

| 微距镜头 | 近距离细节，倍率可选 1:2、1:1 | 写具体部位、倍率与清晰范围，核对工作距离 |
| 移轴镜头 | 位移调整构图，倾角调整焦平面方向 | 位移与倾角分别写，明确希望保留的结构与线条 |

| 鱼眼镜头 | 例如对角视场角 180°的鱼眼投影 | 与直线投影区分，不把产品无意拉伸 |

| ARRI Signature Prime | 大画幅电影定焦系列 | 核对记录区域与覆盖，保留系列原名 |
| Cooke S4/i | Super 35 电影定焦系列 | 核对记录区域与镜头覆盖 |

光学类型或系列在全片镜头组中确定，各镜选择所需视场角和对应光学方式。

## 视场角

视频提示词用度数直接描述视角。视场角是当前画面覆盖的角度范围；它与景别、机位方向、俯仰角和观察距离分别表达。例如 `水平视场角 47°；机位在产品右前方 45°，光轴向下 30°`，三个角度描述不同事情。

统一设定中说明视场角口径，默认采用**最终画面的水平视场角**；若用垂直或对角口径，要明确写出。一条片子内沿用同一口径。度数本身直接规定所指方向的可见范围，不需要依赖某个机身的毫米数解释。输出宽高比决定另一个方向的范围，裁切变化后按最终画面核对。

| 视场角选项 | 选用方向 | 写入时落实到当前画面 |
| --- | --- | --- |
| 8°、12° | 很窄的观察范围，远处主体或局部隔离观察 | 指定观看距离与具体部位，不能靠窄视场代替特写边界 |
| 18°、29° | 突出主体或细节，减少周边环境 | 指定完整产品还是局部，背景需要保留什么 |
| 40°、47° | 主体与附近动作、环境需要兼顾 | 指定产品、手、人物之间的关系，哪些部分在画面内 |
| 63°、74°、84° | 更宽的操作范围、人物与空间关系 | 确定前后距离，重要产品避开边缘不必要的变形 |
| 100°、107°、120° | 明确需要的超广空间或趣味视角 | 写投影方式与夸张程度，检查产品比例 |
| 180°鱼眼 | 明确需要鱼眼投影 | 说明水平、垂直还是对角 180°，不当成普通直线投影超广角 |

选项是可调整的参考值，不要求逐项用遍。每镜选明确度数并说明实际构图；不将 `47°` 固定解释成“人眼视角”，也不把 `29°` 固定解释成“压到脸后”。

视场角大不等于远景，视场角小也不等于特写。主体在画面里的大小还由距离和构图决定；窄视场在远处也能拍全身，宽视场贴近时也能拍局部。

## 景别与具体取景

景别是当前画面的取景范围；不等于视场角、机位高度或光圈。

| 景别 | 用途 | 一种具体取景示例 |
| --- | --- | --- |
| 大特写 | 观察局部结构、纹理或短促反应 | 耳环搭扣与相邻一小段链条入画，完整耳环在画外 |
| 特写 | 看清明确部位、表情或操作 | 杯盖、杯口与旋盖手指入画，杯身只露上部 |
| 近景／中近景 | 兼顾主体重点与附近动作 | 女主从头顶取到胸部下方，胸前的杯子和持杯手完整入画 |
| 中景 | 观察操作或关系 | 咖啡机、操作双手与接杯位置入画，人物头部在画外 |
| 中全景 | 保留主体较多动作范围与周边关系 | 人物从头顶取到膝部，手中包与提放动作完整可见 |
| 全景 | 看整体外形、姿态或搭配 | 模特从头顶到鞋底完整入画，脚边保留地面 |
| 远景／大远景 | 看主体与大环境关系 | 人物全身在岛台旁，冰箱、门口与行走路线同时可见 |

示例不是固定构图。输出时确定当前主体、部位、裁切边界与动作空间，不能保留“脸或物体”“某个细节”等未决词，也不能把人物到腰的范围套给物体。

建立镜头是交代空间的用途，不是额外景别。需要交代位置关系时可以用全景、远景或其他合适取景；不默认先铺环境空镜。

## 机位：高度、朝向、俯仰与滚转

机位回答摄影机在哪里、朝哪里看。以当前主体的正面、台面、眼睛、接缝等为参照；角度是摄影设计值，不是产品事实。先确定主体正面与左右基准，物体没有固有正面时以参考图或当前操作面确定；不能把主体右侧、观察者右侧和画面右侧混用。按任务选具体角度，不能只留下“稍高”“侧一点”。

### 水平观察方向

| 机位 | 可选方向参考 | 需要交代什么 |
| --- | --- | --- |
| 正面 | 朝向主体正面，水平偏角约 0° | 哪一面是产品正面、哪些结构需要可见 |
| 前侧三分之四 | 左前或右前约 30°、45°、60° | 看清正面与哪一侧，重要标识不能被遮住 |
| 正侧面 | 左侧或右侧约 90° | 强调厚度、轮廓、切面或动作关系 |
| 后侧三分之四 | 左后或右后约 120°、135°、150° | 背面结构或人物视线关系，别误把背面当正面 |
| 正后方 | 约 180° | 背部、行走方向或人物面向的对象 |
| 肩后 OTS | 指定谁的左肩或右肩后 | 前景肩膀占位、对方或操作对象的取景范围 |
| 主观 POV | 人物眼睛、手持设备或工具的观察位置 | 谁在看、看到什么，视角是否符合人物动作 |
| 贴近物体的机位 | 杯沿、桌边、包内开口等明确参照 | 镜头能否进入，是否会遮挡、穿模或虚构内部 |

### 高度与俯仰角

下表以镜头光轴相对水平线为准；俯拍向下，仰拍向上。相机高度与光轴角度分别写，不能互相代替。

| 机位选择 | 角度或高度参考 | 用途与约束 |
| --- | --- | --- |
| 眼平／物平 | 与眼睛、杯身中部或目标接缝齐平，俯仰约 0° | 自然观察形态；目标不在画面中心时可略微调整光轴 |
| 低机位 | 台面高度、膝部高度或贴近地面 | 从下方观察体量与姿态，明确实际向上角度 |
| 仰拍 | 向上 15°、30°、45° | 强调高度或动作；注意正面标识与面部变形 |
| 轻俯拍 | 向下约 15° | 略看见上表面，同时保留正面 |
| 斜俯拍 | 向下 30°、45°、60° | 操作、开口内部、桌面关系；不能默认都能看见侧面 |
| 高机位 | 高于头顶、货架或台面 | 交代空间，给出观察方向与俯角 |
| 正俯拍 | 向下 90°，镜头光轴接近垂直台面 | 平面排列、搭配与操作；通常看不见垂直侧面的完整标识 |
| 极低仰视 | 接近地面或台面向上观察 | 特定张力或趣味视角，检查遮挡与产品比例 |

### 水平倾斜与特殊机位

- **荷兰角／倾斜机位**：例如画面顺时针倾斜 10°、15°或 25°。这是滚转角，不等于从侧面拍，也不等于仰拍。
- **反射机位**：明确通过哪面镜子或反光面观察，镜中与镜外的位置、文字方向要成立。
- **水下、容器内、探针或剖面视角**：指定设备或虚拟观察方式及可见结构。不能借特殊机位编造真实产品内部。

不要把所有角度一起写进提示词。一个典型完整描述可以是：`产品右前方 45°机位，摄影机高于杯口，光轴向下 30°；杯盖与杯口完整入画。`

## 构图与空间关系

构图安排画面内的位置、大小、遮挡与前后关系，与机位及景深分别处理。

| 构图方式 | 具体可用描述 | 选择依据 |
| --- | --- | --- |
| 居中／对称 | 产品正面居中，两侧空间接近，垂直线保持竖直 | 结构、正面识别或仪式感 |
| 三分构图 | 产品位于右侧三分线，左侧留出手进入的空间 | 主体与动作空间分配 |
| 对角线 | 刀、食物或手部动作沿左下至右上的方向排列 | 强调动作路径；不等于必须倾斜摄影机 |
| 前景框景 | 门框或前景物位于边缘，主体关键部分无遮挡 | 观察位置、层次或人物关系 |
| 前中后景层次 | 前景是手、产品在中景、人物在后景；按需要确定大小和遮挡 | 有明确空间信息时使用，不要求每镜三层齐全 |
| 留白与动作空间 | 在人物视线方向或产品运动方向保留空间 | 便于理解动作，预留文案时明确区域 |
| 整体与局部 | 包的完整轮廓入画；或只取包扣与周围皮面 | 明确裁切边界，不能只写“主体占大部分” |

构图比例可以作为设计值，例如产品约占画面高度三分之二；没有实际必要就不强制每镜写比例。运动过程中检查边界，不能起幅完整却在关键动作中把手或产品截掉。

## 光圈

光圈是镜头参数，不等于景深；景深还与观察距离、光学设计、记录画幅和放大倍率有关。可调光圈在镜头支持范围内选择；手机等固定光圈设备采用该机型既定规格，不能为其编造可调 f 值。需要不同清晰范围时可调整机位距离、光圈或选择设备实际支持的处理方式。

| 光圈选择 | 可用具体值 | 何时考虑 |
| --- | --- | --- |
| 大光圈 | f/1.4、f/1.8、f/2；电影镜头按实际 T 值标注 | 暗光或希望浅景深时考虑；先检查手、脸与产品是否在同一清晰范围 |
| 中等光圈 | f/2.8、f/4、f/5.6 | 人物与产品、操作和材质需要兼顾时考虑 |
| 小光圈 | f/8、f/11、f/16 | 产品多部位、台面与微距需要更多景深时考虑；不保证从最近到无穷远全清楚 |

摄影镜头通常标 f 值，电影镜头通常标 T 值。f 值描述相对孔径；T 值考虑透光率，不能不加依据直接当成同一数值，也不当成两个可以任意独立调整的旋钮。可写 `ZEISS CP.3，水平视场角 47°，T4`，再明确本镜希望的景深，不伪算精确景深范围。选择值不能超过镜头支持的最大开口，例如 f/4 镜头不能写使用 f/1.4。

## 景深

景深描述画面中前后方向的可接受清晰范围，与机位运动分别表达。

| 景深目标 | 具体写法 | 核对重点 |
| --- | --- | --- |
| 浅景深 | 水平视场角 29°，f/2；眼睛清楚，后方墙面柔化，人物手中产品若不在同一深度则不要求同时锐利 | 不把需要展示的产品完全虚化 |
| 中等景深 | 水平视场角 47°，f/4；杯身正面与持杯手清楚，较远的书架略虚 | 依拍摄距离判断清晰范围，参数不保证所有构图都相同 |
| 深景深 | 水平视场角 63°，f/8；砧板、双手与主要操作部位均需可辨 | 不是整幅从镜头表面到无穷远全部锐利 |
| 微距景深 | 水平视场角 18°，微距，f/8、1:2；包扣接缝清楚，接缝前后的皮面逐渐柔化 | 微距即使收光圈仍可能景深很浅；工作距离按具体镜头核对 |
| 分区清晰 | 分割近摄镜或明确的生成效果，让前景物与后景人物分别清楚 | 写清这是特殊光学或风格处理，不当成普通光圈的自然结果 |

具体方案从表中选择合适值，并结合主体距离、排列与动作验证。

## 运镜方式

先根据本镜需要强调、跟随或揭示的内容选择运镜，再写具体执行：**起幅 → 方向与路径 → 速度或触发点 → 落幅**。固定镜头也是一种选择；各镜按内容判断，不为凑种类强行运动。

| 运镜方式 | 要确定什么 | 一种具体写法示例 |
| --- | --- | --- |
| 固定镜头 | 摄影机位置、朝向与视场角保持，动作发生在明确范围内 | 固定在杯子右前方 45°，水平视场角 29°；杯盖与旋盖手指完整入画，手离开时切镜 |
| 推镜头 Dolly in | 摄影机向主体靠近，起幅与落幅清楚，视场角是否变化另定 | 水平视场角保持 47°，从完整包身向前推进，结束在包口与提手根部的近景，落幅看清接合位置 |
| 拉镜头 Dolly out | 摄影机后退，从局部揭示整体或环境 | 水平视场角保持 47°，从杯沿细节向后拉，落幅包含完整杯子、持杯手和桌上一角书页 |
| 横移镜头 Truck | 摄影机向左或右平移，前后景关系如何变化 | 从产品正前方向右平移约 20cm，观察方向随产品微调，露出右侧接口；产品保持在画面中央 |
| 左右摇镜头 Pan | 摄影机位置不变，向左或向右转动观察方向 | 从桌上杯子向右摇到人物持杯的手，落幅包含手与完整杯子，动作进入重点时停住 |
| 上下摇镜头 Tilt | 摄影机位置不变，光轴向上或向下转动 | 从向下 30°的手部操作画面向上摇，光轴结束在水平 0°，落幅为人物上半身 |
| 跟拍 Tracking | 跟谁、从哪到哪，保持或改变距离与观察角度 | 从人物右前方跟随她走到桌边，距离基本保持，人物头顶至腰部及手中产品始终可见 |
| 环绕镜头 Orbit | 绕谁、从哪个观察面到哪个观察面，转过多少角度 | 从包的正面 0°沿等距弧线绕到右前方 45°，持续朝向包身，逐渐露出右侧结构，水平视场角保持 47° |
| 升降镜头 | 摄影机实际上升或下降，起止高度与落幅明确 | 摄影机从杯身中部高度升至杯口上方，朝向杯子，落幅看见杯口内部；不是只在原位向下摇 |
| 甩镜 Whip pan | 方向、起点与终点对象、快速模糊段和落幅 | 从人物反应向右快速甩到桌上产品，移动中出现方向性模糊，落在完整产品画面后停稳 |
| 滚转镜头 Roll | 绕画面中心旋转，起止滚转角与方向明确 | 从水平画面顺时针滚转至 15°，产品保持居中，关键结构不被画面边缘裁切 |
| 变焦推近 Zoom in | 摄影机位置不变，视场角由宽收窄 | 摄影机不前移，水平视场角从 63°收至 29°，从人物上半身收至面部，表情落下时停住 |
| 变焦拉远 Zoom out | 摄影机位置不变，视场角由窄展开 | 摄影机不后退，水平视场角从 29°展开至 63°，从产品局部展开到产品与使用场景 |
| 急推变焦 Crash zoom | 在明确动作或反应点快速收窄视场角 | 人物停顿时，水平视场角快速从 63°收至 29°，落幅停在面部反应；不是整体视频加速 |
| 推拉变焦 Dolly zoom | 摄影机前后移动与视场角反向配合，保持主体画面大小 | 摄影机后退同时将视场角收窄，让产品大小接近不变、背景关系变化；靠近时采用相反配合 |
| 穿越镜头 | 连续穿过或经过什么、观察路径与终点是什么 | 沿桌面低机位向前穿过两个已存在的杯子之间，落在后方完整产品上，路径不穿过实体 |
| 高空推进／俯冲 | 高处的起点、路线、下降幅度及最终观察对象 | 从厨房上方斜向前下方推进，结束在岛台上的操作画面，过程中连续看清目标位置 |

表中数字与画面是表达示例，按当前主体、空间和时长调整。实际写法保留当前镜头需要的参数，不把示例中的包、杯子或人物原样套给其他产品。

推、拉、移、跟、环绕和升降主要改变摄影机位置；摇与滚转改变朝向；变焦改变视场角。这些原理用于检查具体写法，选用时统一从运镜方式表决定。快切仍写在剪辑部分。

一个镜头可以有清楚的复合运镜，例如“向右横移，同时摇摄保持产品居中”；写明主路径与配合关系，不能同时要求相反动作。具体速度按动作与观看需要分配，可以写匀速、逐渐加快、在接触点停住等；需要定量时给出与空间和时长相容的设计距离或转角。

推近时不一定改变视场角，变焦推近时不一定移动摄影机。近距离细节运动还需保持合理工作距离与景深，不能一边锁定微距接缝，一边无说明地大幅前移。

## 剪辑与镜头衔接

剪辑决定什么时候切换观察画面，与运镜、景深、视场角分别处理。

- **硬切**：在指定动作或信息点切到下一具体画面。
- **动作匹配切**：两镜继承同一动作阶段与方向；需要省略过程时应明确写跳切，不假装完全连续。
- **跳切**：明确省略哪个过程，下一镜从哪个完成状态开始。
- **快切组**：写清子镜顺序、内容、角度和相对长短，不把多个机位藏在一个连续镜头里。
- **声音跨切点**：对白、动作声或音乐可以延续，但不改变视觉切点的定义。
- **一镜到底**：不切镜，可包含位移、转动和变焦节点；需要足够时间与空间。

多个动作放不下时先删减或明确省略，不用“快切”两字为过多内容兜底。停留是否有价值，按动作执行、信息辨认与感受判断，不给所有镜头平均三秒。

## 播放速度

| 方式 | 具体写法 | 使用条件 |
| --- | --- | --- |
| 常速 | 按自然速度完成本镜动作 | 动作与关键内容都能看清 |
| 慢动作 | 指定哪段动作以 0.5×等速度呈现，明确起止动作 | 细节值得停留，慢放时间计入本镜时长 |
| 加速 | 重复或等待过程按 2×、4×等速度呈现 | 关键操作和结果仍可辨，不掩盖真实使用条件 |
| 速度渐变 Speed ramp | 动作接触前常速，接触瞬间慢放，随后回常速 | 写清触发点及前后快慢关系 |

主体动作速度、摄影机移动速度与剪辑节奏分别决定。主体常速也可以用快切，快速运镜不等于整段视频加速。

## 照明与白平衡

照明至少考虑光源方位、软硬、明暗比、色温和反射控制；白平衡决定色彩还原，不能与光源色温混用。下表的灯位角度沿用已确定的主体／场景坐标，0°为主体正前方；灯光与摄影机是两个不同的位置，移动摄影机不能重新以画面左右解释灯位。

| 照明方式 | 可用具体设定 | 作用与约束 |
| --- | --- | --- |
| 主光＋补光 | 主光在产品左前 45°、高于产品向下约 30°；右侧低强度补光 | 先看清主体形状与标识，补光不抹平全部层次 |
| 侧光 | 左侧或右侧约 90°，软光或硬光另定 | 表面纹理、轮廓和厚度；注意强反光材质 |
| 侧逆光／轮廓光 | 右后方约 135°，前方适量补光 | 液体透光、边缘高亮、主体与背景分开 |
| 背光 | 接近正后方 180° | 透光或剪影；若承担标签辨认要另补正面 |
| 顶光 | 上方接近 90°向下，光源面积与软硬明确 | 台面操作、几何影子或明确气氛 |
| 负补光 | 主体一侧放黑旗吸光 | 增加局部明暗层次，不等于整幅欠曝 |
| 大面积柔光 | 柔光箱、柔光布或窗光 | 玻璃、金属和包装表面形成可控反射，不自动变成雾 |
| 硬光 | 小面积或直射光源 | 边缘清楚的阴影；角度与曝光避开标识过曝 |
| 场景内光源 Practical | 台灯、橱柜灯、路灯与窗光 | 各道光的照射方向与位置对应，混合光可以来自不同侧 |

色温可选 3200K 钨丝灯参考、4300K 中间色温、5600K 日光参考、6500K 较冷日光参考；实际环境不固定只有这些数值。写明数值属于灯还是相机白平衡。例如：`窗光约 5600K，背景台灯约 3200K，相机白平衡设为 5000K；产品正面保持接近参考图的本色，背景台灯呈暖色。`

灯光比可用作明确设计，如主补照度约 2:1 或 4:1；必须说明比的对象，不把灯功率、光源照度和主体亮暗区的曝光差混为同一数值。产品还原优先，机位变化不能让灯凭空跟着转动。

## 交付前逐项核对

- 机身、记录画幅、镜头组、风格是否只在全片开头声明，分镜正确继承？
- 设备和镜头名称是否准确，记录区域与镜头覆盖是否相容？
- 各镜是否用具体视场角描述视角，水平、垂直或对角口径是否一致？
- 机位角度与光圈等设计值是否具体，且与当前取景成立？
- 景别是否落实为当前主体与取景边界，动作时是否会截断关键部位？
- 光圈与景深是否相容，需要看清的部位是否可辨？
- 运镜方式、具体路径、起落幅和速度是否明确，是否与剪辑和播放速度区分？
- 参数与动作在时空上是否成立，是否存在微距大幅推轨、固定机位却改变观察侧等矛盾？
- 场景光源与白平衡是否正确，照明与全片风格是否一致，产品识别色是否可信？
- 是否全部属于一条 Seedance 2.5 请求，没有新造接口参数或承诺精确卡帧？
