# 拍摄设定

图像和视频都用本文件选拍摄设定。提示词用中文写。写进提示词的是下表「写入」列的中文句子。编号和名称只用来挑选，不写进正文，也不要把这些句子再翻译成英文。

本文件是词库：机身、镜头、视场角、景别、光圈或景深、光、色板、类型、调色、运镜、运镜风格，以及可选的变速。这里不规定这些句子放在整段还是分镜。

## 怎么选

- 每个维度最多一个。省略就是未指定，不要写「自动」或「默认」。
- 优先级：用户已经写明的约束和参考职责 > 点名的预设 > 类型里还没被占用的光和色 > 省略。
- 光圈和景深只写一种。
- 类型不是第二套设备，也不是第二套色板。它只补还没写的光和色，表里没有运镜句。
- 调色只替换重叠的反差、饱和、颗粒、辉光、曝光，其余保留。`{target}` 换成中文程度，例如 `略高`。没有程度就整条不写。
- 运镜写路径。运镜风格写操作者或镜头气质，不代替那一条路径。变速写快慢，不代替路径。静帧可以不选这三项。
- 推近和拉远要同时写起幅和落幅。选了它们，就不要再锁一个固定视场角。
- 经典静止只和固定机位一起用。静默机械不要和手持、亲密观察、纪实抓拍、粗粝混乱叠成一句。后四者也不要和固定机位或静默机械叠成一句。
- 先消掉互相打架的句子，再写入。不要把整表拼进一条提示词。
- 微距自带很近的景别。用户要深景深时，去掉微距里的薄焦平面或背景化开，只留表面细节。
- 同一段只有一个视场角。景别可以另写：它决定主体在画面里有多大，不代替视场角。
- 选了 iPhone 原相机，机身只写那一句中文。不要同时写入镜头、焦段或视场角、光圈、景深、色板、类型、调色，也不要再写胶片感或另一句色调。景别、运镜、运镜风格、变速仍可另选。
- 不要写机身品牌或镜头商品名。写可见结果。iPhone 原相机只允许它那一句中文里的原相机说法，不要再加型号或镜头商品名。

## 视场角

度数只用后面「焦段」表里的数，不要写 23° 这种表外的数。同一幅画面只有一个视场角。选了某一行，就不要再写一个不同的度数。没编号的度数直接写那一行中文，不要再叠一条有编号的焦段。

景别另写一句中文，不代替视场角：

| 景别 | 写入 |
| --- | --- |
| 大特写 | `一个细节的大特写` |
| 特写 | `特写，脸或一件物体占满画面的大部分` |
| 中近景 | `中近景，头和肩` |
| 中景 | `中景，大约到腰` |
| 全景 | `整个人或整件物体的全景` |
| 远景 | `远景，主体和周围的地方` |
| 建立镜头 | `这个地方的建立镜头` |

`29° 的中近景` 和 `47° 的中景` 不是同一帧。两个都重要时两个都写，用中文。

宽（约 63–84°）会拉开空间，脸贴得太近会在边缘变形。47° 接近被当成真的透视。29° 把背景压到人后面。18° 及更窄是从远处看，空气会被压进画面；需要距离感时写明尘或热浪。

背景按前景、中景、远景写。光写明从哪一侧来；主体亮、靠观察者这一侧落在影子里时，人和背景分得开。

需要写色温时全场只用一个中文句子：`3200K 暖色实用光`、`4000K 混合室内光`、`5600K 日光`、`8500K 冷色阴天或开阔阴影`。没有原因就不要中途改。

## 例子

用户说「暖一点的胶片人像，脸清楚，背景化开，窗光」。

选 CB08、LN06、FL05、DF01、LT04。光和色已经指定，类型不再加。没有程度，调色不写。光圈不写，因为已经写了景深。

写进提示词的只有这些中文句子：

```text
有胶片纹理但颗粒不重，高光滚降柔和，肤色自然。中间调透出金色暖意，肤色讨喜，边缘衰减柔和。29° 视场角，背景收到脸后面，主体从房间里分离出来。主体极清晰，背景化成没有可读细节的柔和形状。来自左侧窗户的有动机日光，方向和房间一致，向远墙衰减。
```
