# 开场钩子

复杂商业片、信息流、产品广告、UGC 转化，或用户明确要强化开头时，写提示词前先读本文件。简单的一件事（同一时空、一个连续动作）仍走 `seedance-提示词写法` 的路径 A，不必为了钩子拆镜。

本文件只检查开场。提示词用中文写。比例、时长、分辨率留在 `seedance-2` 或 `seedance-2.5` 的使用说明里，不写进正文。多镜时，开场镜再交给 `分镜脚本`，编译成路径 B 的第一镜。

## 前三秒要完成什么

片长达到 3 秒时，开头先设计完再写后面。短于 3 秒时，第一帧同时完成三件事：触发、认得出主体、留下要记住的那一点。

达到 3 秒时，前三秒完成这四件：

1. **第一帧已经在事件里。** 动作、决定、反应或冲突进行到中段，并带最低限度的情境：谁、在哪里，或哪段正常生活刚被打断。产品不要孤零零等着开场。
2. **状态在三秒内变掉。** 约 0.7 秒内发生触发，约 2 秒内发生决定性的那一下，第 3 秒的结束状态和第一帧一眼能分开。前两秒不用来静止拿着、等待、慢推或普通陈列。
3. **观众能说出还想知道什么。** 例如谁会拿到、为什么突然停下、这一下会造成什么结果。
4. **事件连着这条片的理由。** 由产品、质地、声音、使用结果、受众正在碰到的麻烦，或核心主张触发。

先给注意力事件，再补世界和原因。片长到 30 秒，只加解释、证明和情绪，开场效率不降。后面按这个顺序接：钩子、情境、产品因果、证明或体验、兑现、收束。后段回答前三秒提出的问题。

「约 0.7 秒」「约 2 秒」「第 3 秒」只用来检查开场有没有发生。提示词正文不写时间码。Seedance 2 与 fast 用 `Shot 1` 起句，2.5 按 `seedance-提示词写法` 处理秒数。

把第一秒写成已经在进行的连续动作。模型容易把「先展示，再在零点几秒后开始」拉成两秒静止。正文写「第一帧动作已经开始」。静止持有停在约 0.5 秒以内。

快切要让观众看见完成：关上、盖上、碰到、放下、打开，切走前留大约 0.15 到 0.35 秒，或让下一镜第一帧继承这个结果。有意停在未完成，下一镜马上回答。

0 秒和 3 秒要在主体状态、尺度、空间关系或人物决定上有一眼可见的差别。只变红、只推近、普通液滴落下、粒子变多，单独不够。

自检填完才算钩子：`第一帧看到____；三秒内____发生；这件事让人想知道____，并指向____。`

再答四句：谁正在做什么，或什么正常情境刚被打断；观众为什么关心这个动作做不做得完；产品为什么在这一刻出现；后面哪一段兑现这个欲望、问题或结果。答不上来，画面再反常也只是形式。去掉名字之后任何产品都能用的「高级画面」，不算钩子。

## 钩子类型

一条片选一个主类型。类型是起点，不是要求每条出三稿。

| 类型 | 第一帧已经是 | 三秒内 | 适合 |
| --- | --- | --- | --- |
| 产品异常 | 产品正在打破尺度、空间或物理预期 | 异常落到一个看得懂的结果 | 科技、汽车、美妆、高端产品。观众要知道为什么值得看 |
| 感官微距 | 液体、材质、声音或触感的极致瞬间 | 质地完成一次看得见的变化 | 食品、饮料、护肤、香水 |
| 感官打断 | 一段认得出的日常正在进行 | 产品声、触感或气味把它打断 | 食品、饮料、数码、家电 |
| 未完成动作 | 争夺、递交、使用或选择进行到一半 | 结果出现前切走，下一镜立刻回答 | 零食、饮料、服务、生活方式 |
| 结果先行 | 一个令人好奇的结果已经在 | 回到造成结果的那一下产品动作 | 功能型产品、生活洞察 |
| 痛点打断 | 熟悉的麻烦发生到一半 | 产品介入，状态改变 | 家电、数码、日化 |
| 视觉矛盾 | 同一画面里两个不能并存的状态 | 矛盾指向这条主张 | 概念片、有世界观的商业片 |
| 人物瞬间 | 决定、反应、失误或关系转折的中段 | 决定或反应落地 | 情绪叙事、服务 |
| 共鸣动作 | 受众认得的任务停在未完成 | 看见原因或改变 | 信息流、教程。要有具体对象和处境 |
| 结果反差 | 同一对象、构图稳定 | 只改一个关键变量，结果落定 | 前后对比。同时换光、换色、换主体就看不出产品做了什么 |
| 可读意外 | 一件和能力或主题相连的异常正在发生 | 引出问题，后文给可信解释 | 意外来自动作、尺度、声音或构图 |

食品优先感官打断、人物瞬间或未完成动作。孤立的破裂、放大、悬浮、打开异世界，要有受众欲望、现实冲突或后续因果才用。

钩子和角度分开。钩子是前三秒怎么停住；角度是观众为什么在乎：价格、担心、身份、好奇或证据。换首帧、换字色，购买理由没变，就还是同一条角度。新的一条测试改的是购买理由。

## 伪钩子

这些开场记在黑名单里，写进正文前换掉：

- 城市航拍、建筑外景、日出日落、空房间占满前两三秒
- 人慢慢走进房间、坐下、回家、醒来，或准备开始
- 产品在暗处慢慢显形，没有事件
- 产品居中夹着、悬浮或摆着一两秒，然后才破裂、发光、打开
- 看不出是谁、在哪里、为什么是现在的孤立异常
- 只有灯光、粒子、烟雾和慢推
- 先出标志或口号，画面没有问题和变化
- 与产品无关的猎奇，后面再解释
- 口播第一秒就对镜头念完一句广告，前面没有人的动作

前三秒用过的主要动作、核心景别和视觉异常，中段不要用同一主体再做一次，承担同一个食欲、质地或情绪任务。要回收时，改叙事意义和构图。

## 从动作中间进入

UGC 和信息流尤其如此：前三秒看起来像广告，人会划走。人看的是人在做事。

开场从动作中段进来，再说话。开箱、反应、涂、倒、按、咬、点开结果，这些已经发生了，第一句人声才进入。脚本化的钩子句如果前面没有这个人的瞬间，就还是广告。

口播的前三秒同时拉起三样：人、问题、证明线索。人脸开场时，第一秒里要有表情、手势、道具或问题；三秒内出现产品、方法、屏幕或场景证据中的一样。一个固定中景把三秒念完，不算钩子。

## 首帧等于定向

滚动时观众先看见的是画面。同一房间、同一光线、同一构图，只改标题、字幕或口播，看起来仍是同一条。

要让一条新片子在一瞥里不同，优先换：人、场景、形态（视频和静帧）、景别（生活场景和产品特写）。再叠明显不同的首帧、声音和光线，差别更稳。单独改标题、贴字、字幕样式或同一画面上的文案，差别不稳定。

首帧里的场景在选人。夜晚卧室、健身房、厨房台面，各自叫来不同的人。写开场时写清人在哪里、画面里有什么、这个环境在对谁说话。错的人在第一帧划走，后面的文案没有机会。

发布前把新的一条和已经在跑的放在一起看约一秒。一瞥像同一条，就改首帧、场景或景别，再考虑文案。

## 声音转场要点

前三秒的声音只做一件事：建立视角、确认动作、制造期待，或把观众接回后面的正文。

- 产品声、接触声、环境里被打断的那个声音，可以就是钩子。一整条铺底音乐代替事件，开场是空的。
- 静音也要能认出主体、变化和用途。理解不靠歌词或旁白单独成立。
- 从后段借一个短乐句做冷开场时，写清它从哪一句来、落在成片哪一拍，并核对节拍和尾音接得回正片。
- 切到下一镜时接住上一镜的声音：同一声延续、结果声回答，或人声在动作之后进入。三秒一到就换成无关的音乐，钩子就断了。
- 口播先看见动作，再开口。第一句人声不盖住还没发生的动作。

## 写进正文

路径 A：把钩子写进那一句事件，第一帧动作已经开始，结束状态看得见。

路径 B：第一镜就是这个钩子。景别和一种运镜按 `seedance-提示词写法` 与 `拍摄设定` 写，本文件不另给镜头词库。第一镜写完，用上面的自检句对一下，再写后面的镜。
