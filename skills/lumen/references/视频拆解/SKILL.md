# 视频拆解

用户明确要求拆解、拉片、按镜头分析一条成片时，再运行 `lumen breakdown`。不要因为对话里出现了视频就自动拆解。

只传视频。不要传 prompt。不要传 `--prompt` 或 `--prompt-file`，不要自己写拆解提示词，也不要把内置拉片表再贴进命令。CLI 在省略提示词时会带上拉片表。

```text
lumen breakdown --video <file>
```

用户明确要提交时才加 `--execute`。默认 `--dry-run` 只记请求。如果输出 `running` 并提示 `lumen runs resume <id>`，任务还在服务端跑，执行那条命令接着等，不要重新拆解。

拆解固定 `scene=editing`。默认模型 `doubao-seed-2-1-lite-260915`，`level` 为 `Quality`，需要音频。不要问用户改这些。

## 结果怎么展示

模型的回答可能是一张表。展示给用户时不要用 14 列宽表。每个镜头单独一节，字幕/台词放在这一节最上面，其余字段各占一行：

```text
镜头 3
字幕/台词：……
起止时间码：……
时长(秒)：……
概述：……
叙事作用：……
景别：……
画面元素：……
镜头运动：……
转场/剪辑：……
声音/音乐：……
情绪/节奏：……
视觉风格：……
备注/置信度：……
```

听不清或看不清的字段写「未识别」。不要并成宽表，不要省略镜头。
