# Seedance 提示词写法

本文件的说明用中文。提示词用中文写。模板、样例、默认约束都是中文。真实设备、镜头的品牌型号和指定台词保留准确原名；这不属于把提示词翻译成英文。不要把中文正文另译成英文。

本文件只写提示词，不提交任务。`seedance-2`、`seedance-2-fast` 的形态、时长、比例、素材和提交见 `../seedance-2/SKILL.md`。`seedance-2.5` 见 `../seedance-2.5/SKILL.md`。那些数字不写进提示词，也不在这里再列一张表。

摄影层级与选项以 `../拍摄设定/SKILL.md` 为准。真实设备与镜头名称保留准确原名，具体取景按当前主体写。

- **全片设定**：机身、记录画幅、镜头组、整体视觉风格与摄影默认值放在开头一次声明，所有镜头继承。
- **场景与每镜**：场景说明光源、白平衡与空间条件；每镜写视场角、景别与具体取景、机位、光圈、景深、运动和声画动作。已定默认值可省略，变化处保留具体值；单镜修改只在本镜生效。
- **概念分开**：光圈与景深分别说明。运镜按拍摄设定中的方式选择，写名称、起幅、路径、速度或触发点及落幅；快切写在剪辑部分。
- **手机摄影**：手机型号或 iPhone 原相机在全片设定中声明一次，各镜用具体视场角与机位说明画面。固定光圈按设备实际规格处理。

本仓库不写白模、灰模或线框参考。

复杂商业片或信息流，写正文前先读 `../开场钩子/SKILL.md`。用户要脚本、分镜或多镜时，先读 `../分镜脚本/SKILL.md`，写出创意说明和成片镜头表，再按本文路径 B 写成正文。片种拿不准时可选读 `../视频类型/SKILL.md`。这三份只约束创意和结构，正文骨架仍以本文为准。

角色必须念出的原文若用户给的是别的语言，只把那一句放进 `{}`。除此之外，叙述和约束用中文，真实设备与镜头的品牌型号保留准确原名。`[目标]` 这类标签属于正文，不是讲解包装。

## 原则

1. **意图优先**。不改人物身份与数量、关键道具、场景、因果、空间关系、编辑对象、延长方向和故事结果。
2. **先定一种主任务**。生成、编辑、延长只能有一个。又要改原片、又要在片外续写时，拆成两步，每步一条提示词，不要合成一个备选版本。
3. **用模板重写，不要同义润色**。简单的收成一段；复杂的多模态参考走路径 B。编辑和延长用各自的闭环，不套成重新生成。
4. **一份素材一件事**。写进正文的每一份都有明确职责。正文没写到的图、视频、音频不要上传，也不要传去生成。不要在正文里列未使用的编号。
5. **用户指定的映射优先**。已经覆盖的槽位，不要再塞一张未点名的图去「增强」。
6. **少问**。能从文字和可见素材判断的直接写。只有身份、数量、编辑对象、延长方向或关键帧职责等关键歧义确实影响结果且无法规避时，才合成一个问题询问；普通创意、机位和光线由助手决定。不要同时交出可能被提交的临时正文。
7. **提示词用中文写**。正文只留可提交的中文句子。不写分析、评测、密钥、修改理由。`[目标]` 这类标签属于正文，不是讲解包装。
8. **生成参数与摄影设定分开**。输出宽高比、总生成时长、像素分辨率放在参数区，传感器或读取画幅可写入全片摄影设定。成片镜头表上的每镜秒数是例外：Seedance 2.5 的正文写成 `0-4s：`，Seedance 2 / fast 的正文仍不写秒，总时长用时长参数。用户要改画幅或改总时长、而不是改画面里的对象时，不要写成编辑；目标句后加 `这不是视频编辑。` 原片只作内容参考。
9. **不滥加约束**。不要自动加画质包、稳定包、水印、Logo 或分身禁令。用户没要字幕、也没要音乐时，只写 `不要字幕，不要音乐`。
10. **默认一条**。用户没要对比版时只出一条。
11. **事实和观察分开**。名字、年龄、关系、结局以用户文字为准。素材只补直接看见或听见的东西。单人图不要同时定义两个会同时出场的人；多个候选人先一人一图、一组一图。

用户只给了很高的想法、没有主体也没有事件时，问一次：谁、在做什么、有没有参考。不要先编一张脸。已经有泛指主体和清楚动作时，保留泛指，不要为了显得具体停下来。

## 引用、主体、防歧义

按实际上传或用户给出的顺序编号，从 1 开始。写进正文的标记是 `@ImageN`、`@VideoN`、`@AudioN`。用户原稿里的 `@图片N`、`@视频N`、`@音频N` 按同一序号改成这三枚标记，不要把中文标记留在正文里。编号原样保留，不因读不到文件就删掉、改号或改成无参考。读不到就不要声称看过，也不要补只有看过才能确定的五官、音色、动作或布景。

两种主体写法，选一种用到底：

- 短句：`<Subject1> 在 @Image1 中`，或 `@Image1 里的短发女孩`。`@ImageN` 后面先接名词再接动词。
- 要反复用：`把 @Image1 里的波波头和深棕色围裙定义为 <Subject1>。` 之后只写 `<Subject1>`。

一行只定义一个主体、一件道具或一处场景。不要写「人物 A 和人物 B 参考两张图」这种范围句。拆成两行中文。

错误：`@Image1 跑向门口`。数字会粘到动词上。

正确：`@Image1 里的 <Subject1> 跑向门口。` `@Image2 里的女人站在柜台外。`

不要在动作里裸写 `[asset-xxx]`。输入是 JSON 或带素材 ID 的长文时，按媒体出现顺序换成 `@ImageN` / `@VideoN` / `@AudioN`，再替换正文里的 ID。

`Shot 45` 默认是镜头编号，不是 45 度机位。只有用户写了 45 度才当角度。

同一主体多张图：分开写每张补什么，并写明它们是同一个人，成片里只有一个。两个已命名的人不要并成一个主体，也不要拿一张单人图同时定义两个会同时出场的人。

参考视频没说职责时，只继承和任务有关的动作、机位运动、节奏或声音。生成任务不要默认继承参考视频里的人脸、服装和整场布景。视频已经把动作和顺序给准了，就写继承哪些维，不要把每个动作再改写一遍。

忠实改写时保留用户台词；原创脚本可以创作台词，但不编造产品事实、个人亲测或反馈。音频默认只给音色、口音、语速和情绪；用户明确要求沿用音频原句时例外。

映射顺序：用户点名 > 提示词里的描述 > 素材上看得见的内容 > 文件名 > 上传顺序。上传顺序只在用户要求直接出、而且槽位和候选数量一致时，用来打破平局，不证明身份。

确有冲突且无法根据用户意图解决时，集中问一次：左右或首尾帧职责矛盾、编辑对象或延长方向无法判断、同一主体的关键特征相互冲突。跟拍配合摇摄、环绕并保持产品居中等相容运镜不算冲突；只有同一时段要求相反运动或互不成立的取景才需解决。普通风格、光线、机位没有指定时不要打断。

长图或宫格如果是一张图里的很多格，按「可选：宫格分镜」写，不要当成多张独立参考，除非用户已经拆开。人物三视图容易漂，建议用户改成一张无表情大头照加一张全身照；这是建议，不是另一条提示词。超过四人的群像，先在文字里分组，每组写清谁是谁，不要用一张图糊过去。越要锁脸的图，在提示词里越靠前。

## 先定任务，再定路径

| 任务 | 什么时候 | 写进正文的骨架 |
| --- | --- | --- |
| 参考生成 | 新片子，素材提供人、物、场景、动作或声音 | `用 @ImageN 里的短发女孩，生成……` |
| 编辑 | 只改一条原片里的对象、区域或声音 | `严格编辑 @VideoN：……`，再写保留范围 |
| 延长 | 在原片之前或之后接新片段 | `把 @VideoN 在时间上向后延长` 或 `把 @VideoN 在时间上向前延长` |
| 组合 | 借一张图改另一段视频 | `用 @ImageN 里的物体，严格编辑 @VideoX：……` |

不要写「参考 @视频N」来表示编辑或延长。正文里也不要写 `reference @VideoN`。有多段视频时点名 `@VideoN`，不要写 `these videos`。

编辑、延长、组合走**路径 A**：一件事，一段或一组闭环，不拆成影视三段论。

按实际镜头结构选择，不按素材张数或地点数量硬分：

- **路径 A**：确实连续拍摄不切镜的一段画面，或编辑、延长任务的保留范围。动作可以有清楚节点，摄影机可以移动；不能写一镜到底又暗中跳机位。
- **路径 B**：包含切镜、跳切、快切或多个观察画面。即使同一桌面、同一次操作，也可通过俯拍、手部特写、人物反应构成多镜。

默认产品视频使用 Seedance 2.5，一次生成整条、最长 30 秒。路径 B 只是一次请求中的镜头组织，不表示拆成多次生成。路径 A 可以并为一段；路径 B 具有设定、时间线和必要保持。

## 正文四段

能短则短。四段可以并成一段，但这四件事要在：

1. **统一设定与素材**。先写全片机身、镜头组、风格和摄影默认值，再写场景、主体与每份实际素材的职责。
2. **事件与取景**。路径 A 写连续过程；路径 B 逐镜写本镜规格与动作，各镜共同继承统一设定。
3. **时间**。按时间轴组织连续动作或分镜，明确快切、跳切与声音跨镜。
4. **必要保持**。补充身份、道具、数量、空间和声音关系，设备与风格不在这里重抄。

没有素材的纯文字，不要虚构 `@Image1`。用户没写引用，就不要凭空加编号。

## 内容核对

写完用这张清单看有没有漏。缺的补进四段，不要在文末再挂一套包。

具体主体、动作、取景范围与机位，以及必要的场景、光线、设备名称、声音和保持条件。

| 项 | 何时必写 | 缺了怎么办 |
| --- | --- | --- |
| 精准主体 | 必写 | 有图就绑到图上的可见特征，用中文写。只有「一个女孩」就保留泛指，不要发明五官 |
| 动作细节 | 必写 | 写实际动作、起止状态与必要顺序；幅度和速度按内容决定。忠实改写不擅加动作；原创方案可设计动作，但要在时间内完成 |
| 场景环境 | 按需 | 路径 A 可以一句。有场景图就写采用布局、不采用图中人 |
| 机身、记录画幅与风格 | 全片开头一次 | 型号、画幅口径、镜头组、风格清楚，所有镜头继承 |
| 视场角与光学类型 | 每镜或明确继承 | 写具体度数，口径按全片设定；微距、鱼眼等按需指定。不逐镜重列机身和风格 |
| 光圈与景深 | 分别设计 | 选具体 f 值或镜头所用 T 值，另写哪些部位清楚、背景如何柔化；不把光圈数值当作景深保证 |
| 场景光源与白平衡 | 同场一次 | 光源方向、软硬、色温和白平衡明确；换场景只说明实际变化，延续全片风格 |
| 景别、机位、运动 | 各自明确再组合 | 景别落实主体与取景边界；机位写方向、高度及俯仰等具体值；运动独立写路径、起落位置与作用，固定也可。真实设备参数与本次设计值不混淆 |
| 约束 | 按需 | 用户没提字幕和音乐时，只写 `不要字幕，不要音乐`。不要自动加画质包、水印或 Logo |

## 画面写法

1. **写看得见、量得着的画面**。情绪、类型、风格标签改成能拍到的主体、服饰、距离、光线和动作，用中文写进正文。身份和关系仍以用户文字为准。不写空标签，写 `窄巷里的湿沥青反射着店招的品红和青色灯光，两人分站木桌两侧，桌上台灯照亮手边的物件`。
2. **写目标，不堆禁令**。用要出现的状态代替一串禁止。下表左列是用户的限制，右列是写进正文的中文。

| 堆叠的限制 | 写进正文 |
| --- | --- |
| 不要跑、动作别太大 | `以正常步速走过走廊` |
| 不要晃 | `机位锁定，地平线保持水平` |
| 不要多余的人 | `画面里只有这两个人` |
| 不要暗、不要冷 | `温暖的窗边日光，脸上有一块柔和高光` |

3. **参数具体，含义明确**。原创方案可以设计具体视场角、光圈、机位角度、移动距离和速度。设计值要与画幅、取景、动作和时长相容；不能当作从图片测量所得或设备官方性能。保留这些有用参数，再补主体、动作和切点。时间标记与分镜一致，不用无效停留填满片长。

用户明确不要字幕时写 `不要字幕`。只去掉背景音乐时写 `去掉背景音乐。保留对白、口型、环境声、动作声和整幅画面。` 不要把反向说法扩到其他东西上。

内心活动改成表情、动作或台词，不新增事件。先让观众看清原因，再给反应；原因和反应能同框就同框，不要在原因出现之前切成纯脸特写。假装受伤就写皮肤、衣服和道具保持完整，不要写成真的伤口。

## 时间轴

- **Seedance 2 / fast，仅用户明确指定时**：用 `Shot 1`、`Shot 2`，正文不写每镜秒数。各镜明确具体取景、机位、动作和切点，视角以具体视场角表述。总时长交给对应使用说明的参数。
- **Seedance 2.5**：从分镜脚本编译时，用成片镜头表里的秒数，写成 `0-4s：`。时段连续、不重叠、从 0 开始，和表一致。不要改成 `Shot N` 或 `Phase N`。用户已经给了符合这条规则的秒数，表和正文都用他的数字；没给时用表里分配的秒数，不留空。总时长交给 `seedance-2.5` 使用说明里的时长参数，正文不再另写一个总秒数。没走成片镜头表的多段事件，仍可用 `Phase 1`，每个阶段一件主要的状态变化，并写结束时看得见什么。不要为了凑总时长新造对不上事件的 `0–3s`。

`Shot 1` 这种编号是顺序，不是秒。Seedance 2 / fast 的正文只用它。Seedance 2.5 走分镜脚本时不用它，改用表上的 `0-4s：`。

总时长要由有效内容决定，不机械拉长动作或用空镜填满。检查动作执行、辨认与感受停留；超量就精简或明确跳切，停留无价值就缩短。忠实改写不擅增人物、主线与结局；确有时长冲突先解决。交接要写清物件换到谁手里，交出者不再持有。

## 路径 A 怎么组装

单镜、编辑、延长、组合可以写成一段或短标签。单镜明确主体、取景、机位和连续动作；构图变化时说明由主体位移、摄影机移动还是变焦造成，不暗中切镜。编辑、延长则继承相应原片范围。统一设定写设备与风格，动作段写本镜视场角、光圈与景深；手机也使用同一层级。

```text
[任务句]，[主体和素材]，[地点和动作]，[保持不变的部分]，不要字幕，不要音乐
```

参考：

```text
用 @Image1 里的短发女孩，生成她在 @Image2 的窗边吃蛋糕。温暖的日光落在桌上。不要字幕，不要音乐。
```

编辑：

```text
严格编辑 @Video1：把香水换成 @Image1 里的面霜。其他人、道具和背景保持 @Video1 里的样子。不要字幕，不要音乐。
```

延长：

```text
把 @Video1 在时间上向后延长。新画面从最后一帧继续：两个人走到街角停下，面对面。不要改动 @Video1 里已经看得见的任何内容。不要字幕，不要音乐。
```

用户没要音乐、也没要字幕，末尾就这一句 `不要字幕，不要音乐`。不要再接画质、水印或 Logo。

## 路径 B 怎么组装

包含多镜、跳切或快切的参考生成用三段，同一空间也可使用。编辑和延长沿用各自保留范围，不自动重编原片。

**第一段，全片设定、场景与参考。** 一次声明机身、记录画幅、镜头组、整体风格及摄影默认值。定义主体与素材职责，例如 `脸来自 @Image1，服装来自 @Image2`；说明场景光源、白平衡与空间条件。运镜或声音参考点明各自职责。

**第二段，逐镜时间线。** Seedance 2.5 按分镜写连续时间标记，如 `0-3s：`。各镜写本镜视场角、具体取景、机位、光圈或默认值的变化、景深、运动、动作、声音与切点；不重复机身与整体风格。快切组列清各子镜。未改写的参数继承全片或场景默认值，不能把上一镜的临时值自动带到下一镜。旧模型的 `Shot N` 按其说明处理。

商业片和信息流的第一镜必须已经在事件里：第一帧是动作、决定、反应或冲突的中段，这一镜结束时状态和第一帧一眼能分开。开场是否成立按 `../开场钩子/SKILL.md` 检查。同一时空也可合理切换观察点；只有确实不切镜时才走路径 A，不为开头强行拆镜。分镜脚本的成片镜头表留在正文外面。Seedance 2 / fast 的正文从 `Shot 1` 写起。Seedance 2.5 的正文从该表的第一段秒数写起，例如 `0-4s：`。

**第三段，必要保持。** 补充人物身份、服装、产品数量、道具归属、空间与声音关系，不重抄第一段的设备和风格。字幕与音乐按本片已确定的声画方案处理。

完整的多镜正文以 `../分镜脚本/SKILL.md` 中的三镜案例为例：先声明全片设备与风格，再写各镜视场角和具体声画安排。

## 参考

带素材、事件不止一句时，用这些标签。简单任务可以合并相邻段，但不能漏掉实际用到的素材。标签名可以留在正文里，标签里面的句子用中文写。

```text
[目标]
生成 <事件>。核心主体是 <谁>。这不是视频编辑。

[参考]
@Image1 提供 <谁> 的脸、头发和服装。不要用这张图的背景。
@Video1 提供 <动作或运镜>。不要用视频里的人、服装或地点。
@Audio1 提供 <谁> 的声音。

[主体]
<Subject1> 是 @Image1，并保持 <固定特征>。

[事件]
开始：<状态>。
主要事件：<连续动作>。
结束：<谁在哪里，谁拿着物件>。

[保持]
保持 <身份、人数、服装、道具归属和空间方向>。不要字幕，不要音乐。
```

`这不是视频编辑。` 只在用户要的是改构图或改总时长、原片只作内容参考时加。真的编辑、延长、首尾帧，不要加这句。

多素材按这个顺序组织，不要用一句总括让模型自己分配：

```text
[人物]
<人物A> 是 @Image1。只用脸、头发和服装。
<人物B> 是 @Image2。只用脸、头发和服装。
不要交换他们的脸、服装、动作、位置或台词。

[道具]
<道具A> 是 @Image3。它只属于 <人物A>。只有一件。

[场所]
<场所A> 是 @Image4。只用空间、材质和光。不要用图里的人。

[动作与声音]
@Video1 提供 <人物A> 的动作。不要用视频里的人或地点。
@Audio1 提供 <人物A> 的声音和指定的那一句台词。
```

同一主体的正面、侧面、背面写成逐张职责，并写明成片里这个人只有一个。

站位围绕门、桌子、柜台、车这些稳定物体写内外和朝向，不要只写屏幕左侧：

```text
店员留在玻璃柜台里面，面向外。两个顾客并排站在柜台外，隔着柜台对店员说话。
```

站位图上的箭头、框和说明文字不是画面内容。

分场景时每一场只激活这一场用到的人和物，并写结束时的可见状态。下一场承接这个状态。还没写成片镜头表时，可以用 `Phase N`。已经有成片镜头表时，Seedance 2.5 用表上的 `0-4s：`，不要改写成 Phase。

```text
Phase 1：检查员独自站在设备舱前，记录仪挂在腰带上。他们打开舱门，取出唯一的存储卡。结束时卡只在他们右手里。
Phase 2：还在同一间房，他们把卡插进记录仪。结束时屏幕亮着，卡仍在设备里。
Phase 3：档案室。档案员在木桌里面，检查员在桌子外面。检查员把记录仪放在桌面中央，说 {这周的数据已经导出}。结束时记录仪只在桌上。
```

长视频的阶段骨架：

```text
[Phase 1]
开始：<初始状态>。
主要事件：<一件事>。
结束：<看得见的状态>。

[Phase 2]
承接：<必须留下的状态>。
主要事件：<一件事>。
结束：<看得见的状态>。
```

阶段数量跟事件走，不必凑成三段。提示词长了，先留主体、职责、事件和结束状态，压缩重复的风格词。

从分镜脚本编译到 Seedance 2.5 时，按成片镜头表写时间标记，即使用户没给秒数。没走这张表时，只有用户已经给了数字，或明确要求按秒控制交接和进出场，才写：

```text
0-5s：<开始状态>；<一件事>；结束在 <状态>。
5-10s：承接上一状态；<一件事>；结束在 <状态>。
```

分镜可用小数秒表达目标节奏；需要简化时，将短镜编译为时间窗内的明确快切组，保留顺序和相对长短。不要声称模型能精确卡秒或卡帧。

## 严格编辑

编辑必须有一条唯一母版。只描写目标画面、不提母版，会退化成重新生成。

先把原片里看得到的人、动物、道具和背景分成：替换、删除、保持。用户没点名的，默认保持。看不全原片时，不要假装数完了所有人；写完指定修改后，必须加上范围闭环的其中一句：

- 局部修改：`除了上面点名的对象，@Video1 里其他看得见的人、道具和背景元素都保持原样，不被替换，也不被去掉。`
- 用户明确只要留下某些对象：`除了点名要留下的对象，去掉 @Video1 里其他看得见的主体。不要添加没有点名的东西。`

```text
[编辑]
严格编辑 @Video1。只把 <原对象> 改成 <目标>。

[母版]
@Video1 是唯一的编辑母版。它提供原来的地点、机位、运镜、动作路径、遮挡和事件顺序。

[外观]
@Image1 提供 <目标> 的样子或材质。不要用这张图的背景或无关的人。

[范围]
只改 <对象和区域>。整片里目标的数量是 <数量>。
除了上面点名的对象，@Video1 里其他看得见的人、道具和背景元素都保持原样，不被替换，也不被去掉。

[时间线]
<目标> 在相同的入画、路径、速度和遮挡上替换 <原对象>。其他人的动作、运镜和事件顺序保持 @Video1 里的样子。
不要字幕，不要音乐。
```

动态主体换成另一类时，写运动槽位，不要写一长串无关的保持清单：

```text
去掉 @Video1 里从长椅前经过的红色自行车和骑车的人。用 @Image1 里的深灰色巡逻车，在相同的入画、路径、速度和遮挡上替换他们。结果里不再出现红色自行车和骑车的人。长椅上的两个人、树和路保持 @Video1 里的样子。
```

能看清抓取、交接、进出场时，可以加少量条件：`只有椅子关节合上之后，手才松开。` 看不清就不要按抽帧编时间段。编辑不能承诺逐帧重合。

用户点名 `@Image3` 做外观时，不要把另一张更清晰的图写进正文，也不要把它传去生成。

只改声音时，画面、口型时点、镜头和剪辑节奏仍属于母版。不要为了改一句台词重排动作。

```text
[编辑]
严格编辑 @Video1。只去掉整片的背景音乐。

[母版]
@Video1 是唯一的编辑母版。它提供画面、动作、口型时点、机位、其他声音和事件顺序。

[范围]
只去掉背景音乐。

[保持]
保留对白、口型、环境声、动作声和整幅画面。不要字幕。
```

换音色或语言时，默认不改台词内容和张嘴的时点，除非用户明确要改词。

## 延长

只说「延长」、看不出方向时，问一次方向，不要猜。

新片段里同一个人始终是一个连续的身体，不复制、不分裂。转身、被挡住、出画再入画，仍是同一个。这条要写进正文，不能只在分析里检查。

延长只写原片边界之外的新画面。不要同时改 `@VideoN` 里已经出现的内容。边界要接上姿态、道具、背景、机位、光线、声音和运动趋势。不承诺像素级相同。额外参考不能覆盖边界那一帧。

向后，新片段的第一幅接尾帧：

```text
@Video1 是要在时间上向后延长的视频。
@Image1 提供园丁的脸、短发和浅绿色围裙。不要用这张图的背景。
@Image2 提供柳条篮的结构和材质。不要用图里的花园或人。

把 @Video1 在时间上向后延长。延长段的第一帧接上 @Video1 的最后一帧：温室长椅、园丁的位置和朝向、锁定的中景机位、午后的侧光都继续。其他参考不替换这一帧边界。

然后园丁用双手把 @Image2 定义的柳条篮从长椅下拿起，放到身后的中层架子上。结束时篮子只在那层架子上，园丁的手已经离开，人后退半步。

在延长段里，园丁和篮子各自保持为一个连续物体。它们不被复制，也不被拆开。不要字幕，不要音乐。
```

向前，先写原片开始之前发生的事，再把原片首帧写成延长段的结束状态。只写「随后承接原视频」，容易把后面的人或道具提前放进来。

```text
@Video1 是要在时间上向前延长的视频。

把 @Video1 在时间上向前延长。在原视频开始之前，<一件更早的事>。

延长段的最后一帧接上 @Video1 的第一帧：<姿态、道具、背景、机位、光、声音和运动趋势> 对齐。

只在 @Video1 后段才出现的人、道具或效果，不要提前出现。
每个主体保持为一个连续物体。它不被复制，也不被拆开。
不要字幕，不要音乐。
```

## 可选：关键帧

`@Image1 是第一帧。` 单独成句。`@Image2 是最后一帧。` 也单独成句。不要写成 `opening reference` 或 `first-frame reference only`。角色句之外，另起一句写这一帧锁定的构图、位置、姿态、道具、场景和镜头方向。别的图再另起一句，不要和首帧句粘在一起。

首尾帧的画幅要一致。比例和时长本身不写进提示词，冲突交给使用说明。

```text
@Image1 是第一帧。
这一第一帧锁定烘焙台、裱花师的位置、还没装饰的蛋糕，以及正面中景机位。
@Image2 是最后一帧。
这一最后一帧锁定转盘中央的成品蛋糕、裱花师的手已经离开蛋糕，以及同一个正面中景机位。
@Image3 提供裱花师的脸、盘起的头发和白外套。它不改变 @Image1 的第一帧构图，也不改变 @Image2 的最后一帧构图。
@Image4 提供蛋糕的两层、白色糖霜和蓝莓。它不改变第一帧或最后一帧。

画面从 @Image1 的第一帧开始。裱花师转动转盘，在两层上挤出连续的奶油棱，逐颗放上蓝莓，然后把手拿开，到达 @Image2 的最后一帧。
两帧之间蛋糕保持为同一件物体，工具留在原处。不要字幕，不要音乐。
```

多张过程图：第一句先声明顺序，再逐张写关键状态。这是语义锚点，不是要求在某一张上停住，也不承诺逐帧复刻。

```text
按顺序使用 @Image1 到 @Image4，作为关键帧。
@Image1 是第一帧。
这一第一帧锁定 <开场构图和道具>。
@Image2 是第二个关键状态：<这一步结束时看得见什么>。
@Image4 是最后一帧。
这一最后一帧锁定 <结束构图和道具>。
画面按这个顺序经过这些状态，状态之间的动作连续。不要字幕，不要音乐。
```

## 可选：宫格分镜

宫格只提供故事顺序和大致构图，不要求每格细节复刻。写明读取顺序，以及不采用的线、标注、占位人和格子的画法。

```text
@Image1 是九宫格分镜。从左到右、从上到下读，只取镜头顺序和大致构图。不要用格子里的线、文字或占位人。
@Image2 定义 <Subject> 的脸和服装。

Shot 1：<视场角、当前主体、具体取景、机位、动作与地点>。
Shot 2：<视场角、当前主体、具体取景、动作、需要的运动与切点>。
Shot 9：<结束动作，以及结束时看得见什么>。

不要字幕，不要音乐。
```

Seedance 2 / fast 保持 `Shot 1` 这种顺序，正文不写秒。格子编号不是秒，不要把第 3 格写成 `0–3s`。若这些格子要收成成片镜头表，秒数按分镜脚本分配，Seedance 2.5 再用表上的秒数写成 `0-4s：`。

## 情绪、镜头、声音、产品

用户只给了情绪方向时，允许表演自己长出来。用户要控演技时用：情绪从哪到哪、触发事件、一两处看得到的反应、光或声音怎么跟着变。不要把眉、嘴、呼吸、手全部写满。

```text
退回的信被放上桌子之后，沿着杯沿划的那只手停住，她的眼睛落在退信标记上。
眉收紧，笑意离开，她吸一口气，把信翻过去扣在桌上。
她看向对面的空椅子，坐姿没有改变，说 {我明白了}。
```

忠实改写中，用户只给半句就保留半句，不擅自补成长段对白；如果用户要原创脚本，可按内容创作台词。台词必须与动作和时长相容，不编造功效、亲测经历或其他事实。

每一镜按主体与表达选择具体视场角及需要的光学类型，再分别安排景别、机位、光圈与景深、运镜和切点。专业名称和参数保留，不抽象化；景别仍需落实到当前主体，不能照抄释义或把人体范围套给产品。

例如跟随人物：

```text
摄影机在女主斜前方，与她的眼睛齐平，取景从头顶到腰部，右手和杯子完整可见。跟随她从门口走到书桌前，距离基本保持，杯沿不超出画面上边缘。
```

一镜到底写连续经过的人与空间、运镜方式、路线、速度节点和取景变化。运镜从 `../拍摄设定/SKILL.md` 的统一表选择，例如推、拉、摇、移、跟、环绕、升降、甩镜或变焦。可使用清楚的配合动作；起幅、路径与落幅需要成立，推近与变焦推近分别说明。

景深结合光学类型、光圈与取景描述，例如 `水平视场角 18°，微距，f/8，1:2`，再说明哪些部位清楚、哪些前后景柔化。视场角使用全片统一口径，专业参数与当前画面对应。

声音用一种括号，不要混用。括号里的词用中文，除非 `{}` 里是用户指定要念的原文：

| 内容 | 符号 | 写进正文的例子 |
| --- | --- | --- |
| 音乐 | `()` | `(轻柔的钢琴)` |
| 音效 | `<>` | `<远处的钟声>` |
| 台词 | `{}` | `{你好}` |
| 要出现的字幕 | `[]` | `[第一章]` |

音效占用了 `<>` 时，主体名不要再用尖括号，改用普通名字。

台词写：语言（仅当用户指定）+ 说话人 + `{原文}`。用户没指定口音或语种时，不要自行加上地区口音。多人对话逐段写清说话人；忠实改写不擅改原话，原创脚本按已确定文案写。

无对白写 `没有对白和旁白，保留点名的动作声与环境声，不生成对白字幕。` 这不要求人物闭口；吃、喝、呼吸等仍按动作自然完成。

要出现的字，用中文说明位置和时机，文字本身若必须是别的语言，只保留那一串字符：

- 广告语：文字、何时出现、在画面哪一块、怎么出现、颜色。
- 字幕：底部字幕的原文，并写它跟着哪一句声音。
- 气泡：谁说 `{那一句}`，说话时旁边出现气泡，气泡里是同一句。

精确公式、小字标牌和产品参数不能靠提示词保证。正文仍按最好的写法给出；必要时在正文外加一行，说明要靠已经做好的画面或后期，不要把这句写进提示词。

产品不写「展示安装、运行和完成」。写成初始状态、一次操作、看得见的结果。还没走成分镜表时，每一阶段只一件事。走了成片镜头表的 Seedance 2.5，用表上的秒数，不用 Phase。

```text
Phase 1：加湿器关着，水箱是空的，盖子放在机身右侧。操作者拿起水箱，把水加进去。结束时水面在最高刻度线以下。
Phase 2：水箱装回去，盖上盖子，电源键按一次。结束时手离开按键，机身没有挪动。
Phase 3：喷嘴升起一层细的白雾。桌面保持干燥。结束时机身、水箱和盖子与开始时相同。
不要字幕，不要音乐。
```

## 样例

以下片段仅说明路径 A 的连续动作组织；全片摄影设定按本文前述层级声明。示例假定用户已给人物与杯子参考：

```text
用 @Image1 里的短发女孩和 @Image2 里的杯子，生成她坐在窗边喝一口饮料的连续画面。摄影机在她斜前方，与眼睛齐平，取景从头顶到腰部，开场时杯子已在胸前，完整杯子和持杯手保持在画面内。她把杯子送到嘴边喝一口，再降回胸前。机位固定。左侧窗光照亮她和杯子，杯身颜色保持参考图样子。不要字幕，不要音乐。
```

## 交付

用户单独要提示词时，只交可独立使用的中文正文。用户要方案和分镜时，按分镜脚本完整交付，提示词与说明分开，不能被“只交正文”裁掉。正文内的 `[目标]`、`[参考]`、`[事件]`、`[保持]` 可保留，设备与镜头的准确原名可直接出现。

推断出来的映射写进职责段，不另附推理表。正文只出现真正使用的编号。没写进去的素材不要传去生成。

和时长、比例、分辨率或素材上限冲突时，正文照写，正文外最多一句冲突说明，不把这些数字写回提示词。没有冲突就不要这句。两步任务在正文外标明第一步和第二步，并写明第二步用第一步的成片做新母版。两段正文各自仍是中文。

写完再看一遍：

- 主任务只有生成、编辑或延长里的一种；混合任务已经拆成两步。

- 每个用到的素材只有一件事。正文没有未使用清单。提交只带正文里点到的素材。
