# GPT Image 提示词写法

本文件的说明用中文。提示词用中文写。模板、样例、约束都是中文。不要把中文提示词再翻译成英文交给模型。

本文件只写提示词，不提交任务。三支模型共用这一份：`gpt-image-2`、`gpt-image-2.5-flare`、`gpt-image-2.5-sunburst`。选哪一支、比例、分辨率、质量、背景、参考图和提交读 `gpt-image/SKILL.md`。那些参数不写进提示词，本文件也不列参数表。模型名不写进正文。正文里可以写成品自己的方向，例如竖条四格漫画、一张横幅幻灯片，因为那是画面结构，不是像素或比例开关。

没有参考图就是生成。有参考图就是改图或合成。不要把 Seedance 的镜头时间轴、延长、`@ImageN`、`@VideoN`、`@AudioN` 写进这张图的正文。用户原稿里的 `@图片N` 按同一序号改成 `image N`。

## 拍摄设定

用户要设备、镜头、视场、光圈或景深、光、色、类型、调色、运镜、运镜风格或变速时，从 `skills/lumen/references/拍摄设定/SKILL.md` 的「写入」列取中文句子。这里不列预设，不抄整表，不把编号或名称写进正文，也不要把这些句子再翻译成英文。

静帧只有一幅画面，句子不要拆进视频分镜：

- **机身/色调**：机身或胶片感、色板、类型里的光和色、调色。全图只写一次，放在细节或约束。
- **景别**：跟主体的取景写在一起，全图一次。它决定人或物在画面里有多大。
- **运镜**：静帧默认不写。用户明确要镜头运动的观感时，全图只加一种运镜的中文句子。运镜风格和变速不代替那一种运镜。

用户没点这些维度，就用看得见的中文写光线、材质和取景，不要为了凑词打开整张预设表，也不要自造一套焦段或光圈。

机身是 iPhone 原相机时，机身/色调只写拍摄设定里那一句中文：

`iPhone 原相机观感，计算摄影 HDR，干净的数字锐度，色彩和反差与内置相机应用记录的一致。`

不写镜头、焦段、视场角、光圈、景深、色板、类型、调色，也不写胶片感，不再加手机型号或镜头商品名。景别仍可写。用户明确要求时仍可加一种运镜，不写视场角，不写光圈或焦段编号。官方文档里 “iPhone photo” 也能把模型推向实拍；在本仓库里，选了原相机就不要再写这句或任何镜头参数，没选原相机也不要用它代替上面那一句。

相机规格是外观提示，不是物理仿真。即使用了焦段或光圈的中文句子，也不要把它写成真实镜头的曝光计算。

## 原则

1. **先定结果**。写出主体，以及这张图拿来做什么：产品照片、广告、流程图、课堂图、界面、幻灯片、标志、漫画格子。用途决定精细程度和版式，不要只丢一个风格词。
2. **复杂的按四段写**。场景、主体、细节、约束。能短则短，四段可以并成一段，但这四件事要在。简单的一张抓拍不必贴标签。
3. **格式选好改的**。短句、一段叙述、分节、类似 JSON 的字段、指令句、标签，都能表达同一意图。选读起来好改的，不要依赖特殊语法。没有魔法词。
4. **一次一件事**。生成、改图、多图合成只能有一个主任务。又要换场景、又要改衣服、又要换天气时，拆成多步，每步一条提示词。
5. **改图写「只改什么」和「必须留下什么」**。`只改……` 配上身份、几何、版式、光线、文字、周围物体。局部手术还要写明饱和、反差、箭头、机位、旁边的东西都不动。
6. **一张参考一个职责**。按上传顺序从 1 编号。正文写到的才上传。没上传就不要虚构 `image 1`。不要写 `these images`。
7. **一轮只改一处**。上一张结果当作下一步的输入。`和上一张同一风格` 可以带着上文，但关键约束一旦漂了就要重写。每轮看完再加下一句。
8. **不滥加禁令**。用户没提的水印、Logo、画质包不要自动堆上。图中文字、透明背景、身份锁定这些，是任务需要才写。
9. **事实和观察分开**。地点、日期、品牌名、数据、标签以用户文字为准。参考图只补直接看见的东西。读不到图就不要声称看过，也不要补只有看过才能确定的五官或包装文字。
10. **默认一条**。用户没要多个变体时只出一条正文。
11. **提示词用中文写**。正文只留可提交的中文。不写分析、评测、密钥、修改理由。

用户只给了很高的想法、没有主体也没有用途时，问一次：画什么、给谁看、有没有参考。不要先编一张脸。已经有泛指主体和清楚动作时，保留泛指，不要为了显得具体停下来。

## 四段

1. **场景**。地点、时间、天气、背景远近。没有场景的隔离主体就写透明或纯色背景，并写明不要风景。
2. **主体**。谁或什么，在画面的哪，多大，朝哪看，手和物体怎么接触。
3. **细节**。材质、颜色、光线、介质（照片、水彩、扁平矢量、三维渲染）。用户点了的机身/色调放这里，只写一次。
4. **约束**。必须出现的文字、禁止的额外文字、要保留的身份和几何、不要的水印或商标。改图把保留清单放在这里，并在每一轮重复。

位置要写明。标志在右上、主体居中且左边留白、人站在画面中央但视线离开镜头，都是构图，不是参数。

宽幅、低光、雨、霓虹不要只写氛围。补尺度、空气和具体颜色，例如湿沥青反出的品红和青色、人与人之间大约一掌的距离、木桌上的一盏低暖灯。否则模型会用氛围换掉表面的真实。

## 实拍

目标是照片时，正文里直接写 `照片级真实` 或 `真实照片`。同类说法还有 `用真实相机拍的`、`专业摄影`。再写取景和纹理：毛孔、皱纹、磨损的布、日常细节。避免把画面写成棚拍抛光或摆拍，除非用户要的就是棚拍。

下面是抓拍写法。其中 `35mm` 和 `50mm` 只是外观提示。用户已经从拍摄设定选了机身或镜头时，不要再叠这组焦段，改用拍摄设定的中文句子。选了 iPhone 原相机时，这组焦段、胶片颗粒和景深都不要写。

```text
创作一张照片级真实的抓拍：一位年长的水手站在小渔船上。
他的皮肤风吹日晒，皱纹、毛孔和日晒纹理看得见，手臂上有几处褪色的传统水手纹身。
他平静地整理渔网，狗坐在旁边的甲板上。像 35mm 胶片照片，平视中近景，外观提示为 50mm。
柔和的海岸日光，浅景深，轻微胶片颗粒，自然的色彩平衡。
画面要诚实、不摆拍，有真实的皮肤纹理、磨损的材料和日常细节。不要美化，不要重度修图。
```

选了 iPhone 原相机、又要中景时，机身只留那一句，景别可以留：

```text
场景：雨后的窄巷，湿沥青，木摊上有一盏低暖灯。
主体：一名快递员停在摊边，中景大约到腰，低头看纸杯，两只手捧着杯子。
细节：iPhone 原相机观感，计算摄影 HDR，干净的数字锐度，色彩和反差与内置相机应用记录的一致。
约束：照片级真实，真实的皮肤纹理，没有额外文字，没有水印。
```

## 人、比例、视线、动作

写身体在画面里的范围、和周围物体比有多大、视线落点、手和物体怎么接触。这些句子比「自然一点」有用：

- `全身可见，包含双脚`
- `相对桌子是儿童的体量`
- `视线落在打开的书上，不看镜头`
- `双手自然握住车把`

缺了这些，比例、动作几何和视线容易漂。不要用空泛的情绪词代替姿势。身份和关系以用户文字为准；只有「一个女孩」就保留泛指，不要发明五官。

## 图中文字

要出现的句子放进引号，写位置和字体：字重、大小、颜色、对齐、字距。说明出现几次。不寻常的品牌或拼写按字母拆开。然后要求没有额外文字。生成后自己核对拼写和是否认得清。

小字、密信息、多种字体，在命令上用更高的质量档再比较。质量档不写进正文。

广告要把品牌、受众、场景和原句放在同一条里。原句只出现一次：

```text
给一个叫 Thread 的品牌做一张有文化感的广告 / 时装照片。
这是年轻的街头品牌。广告里一群朋友待在一起，标语是 "Yours to Create."
做成面向年轻街头服饰受众的完成度高的战役图：时髦、当代、有精力、有品味。
构图干净，色彩方向明确，姿势自然，并带高级时装摄影的线索。
标语只出现一次，清楚、可读，融进广告版式。
没有额外文字，没有水印，没有无关标志。
```

把产品放进已经有的场景、又要指定广告句时，原句逐字引用，并写没有多余字符：

```text
做一张写实的广告牌样稿：日落时的公路场景里放着这瓶洗发水。
广告牌文字（逐字，不要多字符）：
"Fresh and clean"
字体：粗无衬线，高对比，居中，字距干净。
确保文字只出现一次，并且完全可读。
没有水印，没有标志。
```

难拼的名字先拆字母，再要求只出现一次：

```text
品牌名只出现一次，按字母拼成 F、I、E、L、D、空格、&、空格、F、L、O、U、R。
粗衬线，居中放在标记下方。没有额外文字，没有水印。
```

节日卡和包装只留用户给的那一句：

```text
做一张圣诞节日卡插画。

场景：
温馨的圣诞场景，一只旧泰迪熊坐在纪念品盒里，毛稍有磨损，缝线有过软修补，放在窗边，窗外在下雪。场景暗示孩子已经长大，记忆还在。

情绪：
温暖、怀旧、轻柔、有情绪。

风格：
高级节日卡摄影，柔和的布光，真实纹理，浅景深，有品味的光斑，适合印刷的构图。

约束：
- 只要原创画面
- 不要商标
- 不要水印
- 不要标志

卡片文字只保留这一句（逐字）：
"Merry Christmas — some memories never fade."
```

周边看材质、包装和印刷是否清楚，并保持原创、不侵犯现成商标：

```text
做一件可收藏的动作用具：复古风格的玩具螺旋桨飞机，圆翼，机头有会转的螺旋桨，漆边略有磨损，童年比例，作为怀旧节日收藏，放在吸塑包装里。

概念：
受孩子们冬天玩的简单玩具飞机启发的怀旧节日收藏。要有温暖、想象和童年的惊奇。

风格：
高级玩具摄影，真实的塑料和喷漆金属纹理，棚拍灯光，浅景深，标签印刷清晰，高端零售陈列。

约束：
- 只要原创设计
- 不要商标
- 不要水印
- 不要标志

包装文字只保留这一句（逐字）：
"Christmas Memories Edition"
```

## 改图

编辑句式是 `只改 X` 再加保留清单。短的移除也可以是 `其他什么都不要改`，但对象必须点名。反复改仍会漂：每一轮重述要保住的身份、几何、版式、光线和文字，并检查这一轮是不是只动了那一处。某一块必须和原图像素一致时，不要指望提示词，把改好的区域合成回原图。

只换一把椅子，相机、光线、地面影子和周围物体都留住：

```text
在这张房间照片里，只把白色椅子换成木头做的椅子。
保留机位、房间光线、地面影子和周围物体。
图像的其他方面保持不变。
接触阴影和织物纹理要照片级真实。
```

只拿走手里的花：

```text
拿走这个男人手里的花。其他什么都不要改。
保留这个人、他的姿势、光线和取景。
```

只翻译图里的字，版式、图标和其余图像不动。译完检查有没有漏网的原文，以及有没有多出来的词：

```text
把信息图里的文字翻译成西班牙语。不要改图像的任何其他方面。
```

换衣服时锁住人，只换衣服。光线、阴影和色温要跟原照片走，避免像贴上去。这同样适用于必须认得出的产品和物体：

```text
按提供的服装图给这个女人换衣服。不要以任何方式改变她的脸、五官、肤色、体型、姿势或身份。保留她的相貌、表情、发型和比例。只替换衣服，让服装自然贴合她已有的姿势和身体几何，布料表现要真实。光线、阴影和色温跟原照片一致，使服装融进去，不要看起来像贴上去。不要改背景、机位、取景或画质，也不要加配饰、文字、标志或水印。
```

草图变实拍时，布局、比例和透视按原图，材质和光要符合草图的意图，不要新添物体或文字：

```text
把这张画变成照片级真实的图像。
保留完全相同的布局、比例和透视。
按草图的意图选择真实的材质和光线。
不要添加新的物体或文字。
```

把人放进新场景时，写自然光、可信的细节、身体范围、视线，以及和场景的关系。脸和比例哪些不能变要写明。画面要像有人真的拍到，而不是海报：

```text
生成一张高度真实的动作场景：这个人正在逃离一只体型很大、看起来真实的棕熊，熊在袭击营地。图像要像有人真的能拍到的照片，而不是过度增强或电影海报。
她在画面中央，但视线离开镜头，穿着户外露营的衣服，脸上有土，衣服有撕裂。她明显害怕，但专注于逃走，熊在她身后破坏营地。
营地位于约塞米蒂国家公园，自然细节要可信。时间是黄昏，自然光，色彩真实。一切都要落地、可信、不做风格化，像抓到的一个真实瞬间。避免戏剧性布光、强烈调色或风格化构图。
保留她的脸、面部比例和身份。
```

风格迁移要写参考图贡献的是调色、纹理还是介质，新主体分开写，并限制背景和多余元素：

```text
image 1 是风格参考。只用它的色板、纹理和视觉介质。
生成一个男人骑摩托车，背景是白色。
不要复制原来的主体。不要多余元素，不要文字。
```

## 多张参考

每张图按序号加职责：主体、风格、衣服、背景。写清怎么合、哪一块从哪张搬到哪。被改的主图放在 `image 1`，除非用户已经规定了别的顺序。编号按实际上传顺序，不因读不到文件就改号。

短句可以直接用。第二张图的狗进入第一张的场景，其余不动：

```text
把第二张图里的狗放进 image 1 的场景，就在女人旁边，沿用相同的光线、构图和背景。其他什么都不要改。
```

职责一多，就先分行定义再写动作。衣服图各自只贡献那一件衣服：

```text
image 1：要留下的女人。不要改她的脸、五官、肤色、体型、姿势或身份。
image 2：外套。只把它当外套用。
image 3：靴子。只把它们当靴子用。
只替换衣服。让服装贴合她已有的姿势和身体几何，布料表现要真实。
光线、阴影和色温跟 image 1 一致，使服装不要看起来像贴上去。
不要改背景、机位或取景。不要配饰，不要文字，不要标志，不要水印。
```

同一人的多张图要写明是同一个人，成片里只有一个，并分开写每张补什么（脸、全身、衣服）。两张图里两个已命名的人不要并成一个。一张单人图不要同时定义两个会同时出场的人。越要锁脸的图，在提示词里越靠前。

## 一轮只改一件事

先有一张干净的底，检查，再把这张输出当作下一次编辑的输入。跟进只改一个条件。短跟进是：

```text
把它改成冬天傍晚，正在下雪。
```

身份、产品、文字或机位开始漂时，不要再加新要求。把保留清单写回去，仍然只改天气：

```text
只把天气改成冬天傍晚，正在下雪。
保留这些人、这件产品、广告牌文字 "Fresh and clean"、机位、版式和取景。
除了雪和傍晚的光，不要改饱和或反差。
```

`和上一张同一风格` 可以指向上一轮，但不能代替必须逐字保住的文字、脸或产品几何。那些在漂了之后要重写进这一轮。

多页故事先做一张角色设定，后面换场景时重复定义性细节，并写 `不要重新设计这个角色`。

设定：

```text
做一张儿童绘本插画，介绍主角。

角色：
一个年轻的绘本式英雄，灵感来自森林里的小侠客，穿着简单的绿色连帽短袍、软的棕色靴子，腰带上有一个小口袋。
角色表情和善，眼睛温和，勇敢但温暖。
带着一把小木弓，只用它来帮忙，从不用来伤害。

主题：
这个角色保护和救助小森林动物，比如松鼠、鸟和兔子。

风格：
儿童绘本插画，手绘水彩观感，轮廓柔和，温暖的土色，奇幻而友好。
比例适合绘本（头略大，表情丰富）。

约束：
- 原创角色（不要受版权保护的角色）
- 不要文字
- 不要水印
- 用单纯的森林背景，把角色展示清楚
```

续一页时，环境可以变，衣服、五官、比例和调色板要重复：

```text
用同一个角色继续这本儿童绘本。

场景：
同一个年轻的森林英雄，在冬季风暴之后，轻轻帮一只受惊的松鼠从倒下的树里出来。
角色跪在松鼠旁边，给出安慰。

角色一致：
- 同一件绿色连帽短袍
- 同一套五官、比例和调色板
- 同样温和、英勇的性格

风格：
儿童绘本水彩插画，柔和的光，下雪的森林，温暖而安慰的情绪。

约束：
- 不要重新设计这个角色
- 不要文字
- 不要水印
```

## 透明背景

透明要两件事一起做：正文写隔离主体，命令上把背景设为透明，输出用 PNG 或 WebP。JPEG 没有透明通道。PNG 不要再设压缩，那个开关只属于 JPEG 或 WebP。这些开关不进正文，也不在这里列表。

正文要排除实底、风景、棋盘格和水印。画出来的棋盘格不是透明。头发、玻璃、影子和边缘要留住真正的透明通道，不要涂成格子。后续每一轮都重写 `保留透明背景`，否则下一步会铺回不透明的场景。文件保持 PNG 或 WebP；转成没有透明通道的图会把背景丢掉。

标志要原创、不侵犯，形状在小尺寸和大尺寸都认得清，四周留出空隙：

```text
为一家叫 Field & Flour 的本地面包店做一枚原创、不侵权的标志。
标志要温暖、简单、不过时。用干净的、接近矢量的形状，轮廓有力，负空间平衡。
细节让位于简单，使它在小尺寸和大尺寸都认得清。扁平设计，笔画少，除非必要否则不要渐变。
完全透明的背景。交付一枚居中的标志，四周留出充足空隙，alpha 边缘干净，不要实底、风景、棋盘格或水印。
```

从照片里抽出产品时，几何和标签保持可读，只做轻度修边：

```text
从输入图像里抽出产品，隔离到完全透明的背景上。
输出：产品居中，轮廓清晰，没有光晕或毛边。
产品几何和标签可读性原样保留。
只做轻度修整。不要加实底、棋盘格、风景或影子。
不要重新设计产品；去掉背景，并保留干净的 alpha 透明。
```

下一轮如果还要改这张透明图，先重复透明，再写那一处改动：

```text
只把标签颜色改成更深的绿。
保留透明背景、产品几何、标签文字和干净的 alpha 边缘。
不要加实底、棋盘格、风景或影子。
```

## 按用途写

用途写在开头，用来设定「这是成品」而不是概念图。下面每类都给出可以直接改写的中文正文。

信息图要写过程、受众，以及读者要从图上看懂的关系。标签和事实关系生成后要核对，不要只看好不好看：

```text
做一张详细的信息图，讲一台类似 Jura 的自动咖啡机如何工作和流动。
从豆仓，到研磨，到称重，水箱，锅炉，等等。
我希望从技术和视觉上都能看懂这条流程。
```

漫画一格一个看得见的动作，不要一格里塞完整段剧情：

```text
做一条短的竖向漫画，4 格。
第 1 格：主人从前门离开。宠物被框在他们身后的窗户里，相对玻璃显得很小，眼睛睁大，爪子高高按着，房子突然安静。
第 2 格：门咔嗒关上。寂静被打破。宠物慢慢转向空房子，姿态变了，眼睛因可能性而亮起来。
第 3 格：房子变了样。宠物大喇喇躺在沙发上，像这里归它，旁边有碎屑，阳光像追光一样切过房间。
第 4 格：门打开。宠物端正地坐在入口，警觉而镇定，好像什么都没发生。
```

界面按已经上线的产品来写：层级、间距、真实控件。不要写成概念艺术：

```text
为本地农贸市场做一张真实的手机应用界面样稿。
展示今天的市场：简单的页头，一份带小照片和分类的短摊主列表，一小块「今日特价」，以及地点和营业时间的基本信息。
设计要实用、好用。白底，克制的自然强调色，字体清楚，装饰很少。
它要看起来像一个小本地市场真正在用的、设计良好的应用。
把界面样稿放进 iPhone 的外框里。
```

科学图按教案写：受众、要讲清的关系、必须出现的部件、不要出现的东西。箭头、标签和留白要够学生扫读：

```text
为高中生做一张简单的生物图，标题是 "Cellular Respiration at a Glance"。

展示葡萄糖如何在细胞内变成能量。包含糖酵解、克雷布斯循环和电子传递链。
用箭头连接步骤，并标出主要分子：glucose、pyruvate、ATP、NADH、FADH2、CO2、O2 和 H2O。
做成干净的课堂讲义或幻灯片，白底，简单图标，标签清楚，文字好读。

避免极小的字、多余装饰，或任何让图难以看懂的东西。
```

幻灯片、图表按成品规格写，不要按插画写。交付物、层级、真实文字和数据都放进正文。数字是用户给的；下面的市场规模是示例，换成用户的数，不要假装它们是事实：

```text
做一张路演幻灯片，标题是 "Market Opportunity"，看起来像 YC 背景创业公司真正的 A 轮募资页。

白底干净，现代无衬线字体，类似 Inter，版式利落、少装饰。这一页要包含：

- 一幅用灰蓝做成的 TAM/SAM/SOM 同心圆
- TAM：$42B
- SAM：$8.7B
- SOM：$340M
- 下面一张干净的柱状图，显示 2021 到 2026 的市场增长，趋势轻微向上
- 小脚注："AGI Research, 2024" 和 "Internal analysis"
- 右下角一个公司标志占位

设计要像真正募到钱的那套幻灯片：文字高度可读，数据层级清楚，间距讲究，视觉语言是专业的创业公司风格。

避免剪贴画、图库照片、渐变、阴影、装饰元素，或任何显得通用或过度设计的东西。
```

地点加日期可以带出时代，但衣服、场面和周围环境要自己核对，模型推断不等于史料：

```text
做一张写实的户外人群场景：1969 年 8 月 16 日，纽约州 Bethel。
照片级真实，服装、场面和环境要符合那个年代。
```

分节和类似 JSON 的字段只是同一四段的另一种排法，内容仍然是场景、主体、细节、约束：

```text
{
  "用途": "产品照片",
  "场景": "上午晚些时候，平静水面上的一艘小渔船",
  "主体": "一位年长的水手在整理渔网，一只狗坐在甲板上",
  "细节": "风吹日晒的皮肤，褪色的纹身，磨损的绳子，柔和的海岸日光",
  "约束": "照片级真实的抓拍，没有额外文字"
}
```

## 写完核对

交出去之前看这四件，缺的补进正文，不要在文末再挂一套空泛的画质包：

- 要求出现的文字是否准确、认得清。图解的标签和箭头关系是否对。
- 身份、产品几何、包装文字和参考细节是否还在。
- 改图是否只动了要求的那一处。饱和、反差、机位、周围物体有没有被连带改掉。
- 要透明时，文件是不是真有透明通道，而不是一块画出来的棋盘格或实底。头发、玻璃、影子和边缘要单独看。

然后才决定要不要再开一轮。一轮只加一处修改。提示词用中文写。
