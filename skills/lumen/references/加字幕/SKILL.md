# 加字幕

字幕已经确认，要压进画面时读本文件。只跑 `lumen captions burn`。不要自己调用 ffmpeg。不要调用云端加字幕：那边没有半透明圆角底，位置也只有四个预设。

这一步不识别。没有字幕文件时，先读 `skills/lumen/references/转字幕/SKILL.md`。

## 命令

```text
lumen captions burn --video <file> --subs <file> --to <mp4>
```

这条命令会立刻压制，和雪碧图一样，不默认 `--dry-run`。想先看位置和字号、不写视频时加 `--dry-run`。`--to` 已存在就不覆盖。

`--subs` 可以是：

- 转字幕写出的 JSON。`confirmed` 不是 true 时会拒绝，认可以后加 `--confirm`。
- `.srt` 或 `.ass`。你把文件递进来，就当作已经确认。

可读的 `.txt` 不能拿来压制。ASS 里的方框样式也不会被用上。

## 默认样子

预设可以改，不改就是下面这一套。参考图是白字加半透明灰圆角底。

- 字色 `#FFFFFF`。`--color` 可改，`#RRGGBB` 或 `rgba(r,g,b,a)`。
- 底色 `rgba(70,70,70,0.51)`。`--background` 可改。
- 字号是画面短边乘 `0.039`，四舍五入。1440 的短边约是 56。`--font-size` 给像素。
- 圆角半径是字号乘 `0.45`，左右留白是字号乘 `0.55`，上下留白是字号乘 `0.38`。`--radius-factor`、`--pad-x`、`--pad-y` 改这三个倍数。
- 字体优先 Noto Sans CJK SC Bold，没有就用本机别的中文字体。`--font <file>` 指定文件。

字在灰底里按墨迹居中，不是按字框的几何中心。中文字体的上沿和下沿不对称，几何居中会看起来偏上或偏下。做法是先把字画出来，量不透明像素的边界，再让这块墨迹到灰底上沿、下沿的距离相等。

圆角底不是字幕文件里的方框。每条字幕先画成一张透明图，再用 ffmpeg 叠到画面上。这样才有圆角和 0.51 的透明度。

## 位置

不传 `--position` 时：高大于宽，顶部居中；宽大于或等于高，底部居中。

`--position` 可以是 `top_center`、`bottom_center`、`center`。

边距是相对画面高度的比例，不写死某一种分辨率：

- 顶部：`317 / 2560`。1440×2560 上是 317 像素，大约是 11.4% 再加一点缓冲。
- 底部：`225 / 1440`。2560×1440 上是 225 像素，大约是 14% 再加一点缓冲。
- 正中：字幕块放在画面垂直中央，不用这条边距。

`--margin` 是 0 到 0.45 的比例，覆盖当前这条边的边距。顶部量到字幕块上沿，底部量到字幕块下沿，横着始终居中。

## 工具从哪来

电脑上已经有 ffmpeg、ffprobe 就用电脑的。查找顺序和雪碧图相同：`LUMEN_FFMPEG` / `LUMEN_FFPROBE` 或配置里的 `tools.ffmpeg` / `tools.ffprobe`，然后 PATH，然后本机缓存，最后才下载。可以先跑 `lumen setup ffmpeg`。

压制不会把视频拉长。条目若超出片长，只画片内的那一段。裁掉黑尾是转字幕的事；这里只是不再往片尾外面画。

`--json` 打印宽高、位置、字号、边距、条数和输出路径。
