# 加字幕

识别结果已经写出，要对照口播并压进画面时读本文件。只跑 `lumen captions burn`。不要自己调用 ffmpeg。不要调用云端加字幕：那边没有半透明圆角底，位置也只有四个预设。

没有识别 JSON 时，先读 `skills/lumen/references/转字幕/SKILL.md`。这一步不识别，也不从镜头表、语音记录或出视频提示词里找文案。

压制前必须交出当前这条片子说出口的全部口播：旁白和对白都算，画面上的包装字、字幕条、没被说出来的字不算。文本按说话顺序写成一整段，不要写说话人名字，不要写 `[名字]` 或 `【名字】`。

```text
lumen captions burn --video <file> --subs <json> --speech-file <file> --to <mp4>
```

`--speech "……"` 把口播直接放在命令里。`--speech-file` 是纯文本。不要把 SRT、ASS 或带时间的 JSON 当口播。两个旗标不要同时用。`--confirm` 只放行尚未确认的识别 JSON，不能代替这段口播。

对照只改每条的 `text`。条数、顺序、切分、`start`、`end` 保持识别文件。字按识别到的字对齐，不按时间把一句话摊开。逗号两边如果本来是前后几条，就仍然是那几条，标点贴在相邻的字上。说话人字段原样留着，不写进画面上的字。

自动压制要同时满足：口播里至少 0.85 的字能在识别里找到，识别里至少 0.75 的字能在口播里找到，没有一整段话落在两条之间却没有条目，也没有任何一条会因为删字变成空的。对得上就先压视频，再在识别 JSON 旁边写下 `<名字>.speech.json` 和 `<名字>.speech.txt`。识别 JSON 本身不改。

对不上、没有识别条目、或一条会被改空时，命令停掉，说明原因，不写视频。不要自己补一条，也不要改时间。

## 命令

```text
lumen captions burn --video <file> --subs <file> --speech-file <file> --to <mp4>
```

口播对得上之后会立刻压制，和雪碧图一样，不默认 `--dry-run`。想先看位置和字号、不写视频也不写校对副本时加 `--dry-run`。`--to` 已存在就不覆盖。校对副本已存在也不覆盖。

`--subs` 只能是转字幕写出的 `lumen.captions` JSON。`confirmed` 不是 true 时会拒绝，认可以后加 `--confirm`。SRT 和 ASS 不能拿来压制：那里面的时间不一定来自这次识别。可读的 `.txt` 是口播，用 `--speech-file` 传，不能放在 `--subs`。

## 默认样子

预设可以改，不改就是下面这一套。参考图是白字加半透明灰圆角底。

- 字色 `#FFFFFF`。`--color` 可改，`#RRGGBB` 或 `rgba(r,g,b,a)`。
- 底色 `rgba(70,70,70,0.51)`。`--background` 可改。
- 字号是画面短边乘 `0.039`，四舍五入。1440 的短边约是 56。`--font-size` 给像素。
- 圆角半径是字号乘 `0.45`，左右留白是字号乘 `0.55`，上下留白是字号乘 `0.38`。`--radius-factor`、`--pad-x`、`--pad-y` 改这三个倍数。
- 字体优先 Noto Sans CJK SC Bold，没有就用本机别的中文字体。`--font <file>` 指定文件。

字在灰底里按墨迹居中，不是按字框的几何中心。中文字体的上沿和下沿不对称，几何居中会看起来偏上或偏下。做法是先把字画出来，量不透明像素的边界，再让这块墨迹到灰底上沿、下沿的距离相等。

圆角底不是字幕文件里的方框。每条字幕先画成一张透明图，再用 ffmpeg 叠到画面上。这样才有圆角和 0.51 的透明度。

## 位置

不传 `--position` 时：高大于宽，顶部居中；宽大于或等于高，底部居中。

`--position` 可以是 `top_center`、`bottom_center`、`center`。

边距是相对画面高度的比例，不写死某一种分辨率：

- 顶部：`317 / 2560`。1440×2560 上是 317 像素，大约是 11.4% 再加一点缓冲。
- 底部：`225 / 1440`。2560×1440 上是 225 像素，大约是 14% 再加一点缓冲。
- 正中：字幕块放在画面垂直中央，不用这条边距。

`--margin` 是 0 到 0.45 的比例，覆盖当前这条边的边距。顶部量到字幕块上沿，底部量到字幕块下沿，横着始终居中。

## 工具从哪来

电脑上已经有 ffmpeg、ffprobe 就用电脑的。查找顺序和雪碧图相同：`LUMEN_FFMPEG` / `LUMEN_FFPROBE` 或配置里的 `tools.ffmpeg` / `tools.ffprobe`，然后 PATH，然后本机缓存，最后才下载。可以先跑 `lumen setup ffmpeg`。

压制不会把视频拉长。每条用识别文件里的 `start` 和 `end`。超出片长的，只画落在片内的那一段，字幕文件本身不改。整段都在片外的不画。

视频码率跟源片走，和增强后的颗粒同一套：优先用视频流 `bit_rate`，没有流码率时改用容器 `bit_rate`，并在命令输出里写明。`-b:v` 和 `-maxrate` 用这个值，`bufsize` 是两倍。分辨率和时长不变，音轨原样复制。

`--json` 打印宽高、位置、字号、边距、条数和输出路径。
